# Exercicio de Funcoes em Python

Estudo em Python para praticar criacao de funcoes, entrada de dados e simulacao simples de estoque.

## Visao geral

Este repositorio contem um exercicio introdutorio sobre funcoes (`def`) em Python. O script separa um cabecalho e um fluxo de cadastro/compra em funcoes chamadas pelo terminal.

## Problema resolvido

O projeto demonstra como encapsular blocos de codigo em funcoes reutilizaveis e aplicar esse conceito em uma simulacao simples de cadastro de produto e baixa de estoque.

## Principais funcionalidades

- Funcao para exibir cabecalho.
- Funcao para coletar dados de produto.
- Entrada de cor, estoque e valor.
- Simulacao de quantidade comprada.
- Calculo de saldo restante em estoque.
- Chamada repetida da mesma funcao.

## Como funciona

O programa exibe um cabecalho e chama a funcao de cadastro varias vezes. Em cada execucao, o usuario informa dados de um produto, quantidade comprada e o script calcula o estoque restante.

## Tecnologias utilizadas

- Python
- Linha de comando
- Replit identificado por arquivos do repositorio
- Poetry identificado por `pyproject.toml`

## Arquitetura

Projeto simples com um unico script principal.

## Estrutura do projeto

- `main.py`: script com funcoes e simulacao de estoque.
- `pyproject.toml`: configuracao Python/Poetry.
- `poetry.lock`: lockfile de dependencias.
- `replit.nix` e `.replit`: arquivos de ambiente Replit.
- `venv/`: ambiente virtual versionado no repositorio.

## Status

Projeto de estudo, adequado como registro de aprendizagem sobre funcoes em Python.
